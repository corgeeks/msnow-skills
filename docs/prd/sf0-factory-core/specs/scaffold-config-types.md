# Scaffold package, config, and shared types

## Objective

Create the `factory/` npm package skeleton, the committed `.factory/` directory, the shared domain types every slice imports, and the config loader. When this task is done, `npm test --prefix factory` and `npm run typecheck --prefix factory` both run green against the config tests.

## Suggested Model

Standard: `anthropic/claude-sonnet-5-5`. This is scaffolding plus a validator that follows a fully specified contract.

## Context

The software factory is a local Node daemon that orchestrates agent sessions. Its state lives in a committed SQLite DB. This task lays down the package and the type contract that the store (next task), the HTTP API, and every L1 slice build on.

### Parent PRD

- **PRD**: sf0-factory-core
- **PRD Path**: `docs/prd/sf0-factory-core/PRD.md`. Read Architecture → Module layout, Schema, and Config. The umbrella is `docs/prd/software-factory/PRD.md`.

### Related Tasks

- **Depends on**: none
- **Blocks**: SQLite database and store; HTTP API, SSE, and static UI serving; Daemon lifecycle and entrypoint

## Acceptance Criteria

- [ ] `factory/package.json`:
  - `"private": true`, `"type": "module"`, `"engines": {"node": ">=24.15"}`
  - scripts `"test": "node --test 'src/**/*.test.ts'"` and `"typecheck": "tsc -p tsconfig.json"`
  - devDependencies limited to `typescript` and `@types/node`
  - no runtime dependencies
- [ ] `factory/tsconfig.json`:
  - `noEmit`, `target: esnext`, `module: nodenext`
  - `erasableSyntaxOnly`, `verbatimModuleSyntax`, `allowImportingTsExtensions`
  - `strict`, `include: ["src"]`
- [ ] `factory/.gitignore` ignores `node_modules/` and `ui/dist/`.
- [ ] `.factory/config.json` is committed and holds exactly the config shown in the PRD.
- [ ] `.factory/.gitignore` ignores `main/`, `live/`, `worktrees/`, and `sessions/`.
- [ ] `src/shared/types.ts` exports the contract in Code Examples below, using string-literal unions plus `as const` arrays, and no `enum`.
- [ ] `src/shared/config.ts` exports `DEFAULT_CONFIG`, `loadConfig(path: string): Config`, and `parseConfig(raw: unknown): Config`.
  - Partial input deep-merges over the defaults.
  - A missing file returns the defaults.
  - An unknown key or a wrong type throws an `Error` whose message contains the dotted key path (e.g. `caps.sessionMinutes`).
- [ ] `npm install --prefix factory`, `npm test --prefix factory`, and `npm run typecheck --prefix factory` succeed.

### Technical Constraints

- Node's type stripping executes `.ts` directly. Use only erasable syntax, write `.ts` extensions in relative imports, and use `import type` for type-only imports.
- Only `node:*` imports are allowed at runtime.
- Do not add a CLI, a YAML parser, or anything not listed here.

- `docs/prd/sf0-factory-core/PRD.md`: Schema (column names and enums must match the types), Config

### Code Examples

```ts
// src/shared/types.ts — the contract (fields mirror the SQL columns; timestamps are ISO strings)
export const ITEM_STATUSES = ['draft', 'ready', 'queued', 'active', 'blocked', 'done', 'cancelled'] as const;
export type ItemStatus = (typeof ITEM_STATUSES)[number];
export const RUN_STATUSES = ['pending', 'running', 'paused', 'completed', 'failed', 'cancelled'] as const;
export type RunStatus = (typeof RUN_STATUSES)[number];
export const NODE_STATUSES = ['pending', 'running', 'completed', 'failed', 'skipped'] as const;
export type NodeStatus = (typeof NODE_STATUSES)[number];
export const TIERS = ['heavy', 'standard', 'light'] as const;
export type Tier = (typeof TIERS)[number];
export type GateDecision = 'approve' | 'reject';
export type EventType =
  | 'item.created' | 'item.updated' | 'run.created' | 'run.updated'
  | 'node.updated' | 'gate.opened' | 'gate.closed' | 'retro.recorded';

export interface WorkItem {
  id: number; parent_id: number | null; type: string; title: string; body: string;
  spec_path: string | null; tier: Tier | null; test_cmd: string | null; priority: number;
  status: ItemStatus; source_ref: string | null; created_at: string; updated_at: string;
}
export interface Run {
  id: number; item_id: number; template: string; attempt: number; status: RunStatus;
  branch: string | null; worktree: string | null; pr_number: number | null; pr_url: string | null; head_sha: string | null;
  cost_usd: number; started_at: string | null; ended_at: string | null;
}
export interface NodeRun {
  id: number; run_id: number; node: string; iteration: number; status: NodeStatus;
  model: string | null; session_file: string | null; cost_usd: number; output: string | null;
  started_at: string | null; ended_at: string | null;
}
export interface Gate {
  id: number; run_id: number; node: string; kind: string; question: string;
  recommendation: string | null; opened_at: string; closed_at: string | null;
  decision: GateDecision | null; note: string | null;
}
export interface FactoryEvent {
  seq: number; item_id: number | null; run_id: number | null; node: string | null;
  type: EventType; data: Record<string, unknown>; at: string;
}
export interface Activity { run_id: number; node: string; text: string; at: string } // transient, never persisted
export interface BatchItem {          // POST /api/items/batch input (import + CLI)
  ref: string; parent_ref?: string; depends_on_refs?: string[];
  type?: string; title: string; body?: string; spec_path?: string | null; tier?: Tier | null;
  test_cmd?: string | null; priority?: number; status?: ItemStatus; source_ref?: string | null;
}
export interface BatchResult { ids: Record<string, number>; created: string[]; skipped: string[] }
export interface ItemSummary extends WorkItem { open_deps: number }   // GET /api/items
export interface ItemDetail { item: WorkItem; deps: WorkItem[]; dependents: WorkItem[]; children: WorkItem[]; runs: Run[] }
export interface RunDetail { run: Run; node_runs: NodeRun[]; gates: Gate[] }
export interface Retro {
  run_id: number; failures: string[]; findings: string[]; rework_count: number;
  cost_usd: number; duration_s: number; notes: string;
}
export interface Config {
  port: number;
  roles: {
    planner: string;
    executor: Record<Tier, string>;
    reviewer: Record<string, string>; // author model family -> reviewer model
  };
  caps: { sessionMinutes: number; sessionCostUsd: number };
  loop: { maxBuildAttempts: number; maxReviewRounds: number; maxParallel: number };
  git: { stateCommitPrefix: string; stateCommitDebounceSec: number };
  defaultTestCmd: string;
}
```

## Testing Requirements

- [ ] `config.test.ts`: a missing file returns `DEFAULT_CONFIG`.
- [ ] `config.test.ts`: partial input deep-merges. For example, `{caps:{sessionMinutes:10}}` keeps the default `sessionCostUsd`.
- [ ] `config.test.ts`: an unknown key throws with its path, and so does a wrong type (e.g. a string for `port`).
- [ ] The committed `.factory/config.json` parses to a value deep-equal to `DEFAULT_CONFIG`.
